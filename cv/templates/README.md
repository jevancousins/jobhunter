# CV templates

This directory holds the tracked, generic templates for the CV build system.
Everything personal lives in `cv/variants/` and `cv/sections/header.tex`, which
are gitignored.

## Files

- `general.tex`: structural template for a broadly applicable single-page CV,
  populated with placeholder "Alex Example" content. Onboarding (`/onboard`)
  copies it to `cv/variants/general.tex` (and any further
  `cv/variants/<your-variants>.tex`) filled in from `data/master_cv.json`.
- `seniority_caps.example.json`: example of the per-variant experience caps
  file. The real `cv/variants/seniority_caps.json` is generated by `/onboard`.

## Generated (gitignored) files in `cv/variants/`

- `<variant>.tex`: your real CV variants.
- `seniority_caps.json`: max claimable years per variant.
- `variants.json`: the title-to-variant rule mapping used by
  `scripts/select_variant.py`.

## Header

The contact header is shared by all variants via `\input{sections/header}`.
Create it by copying `cv/sections/header.example.tex` to
`cv/sections/header.tex` and filling in your details.

## Smoke test

`make -C cv template` builds this template (using the example header if you
have not created a real one yet) to verify the LaTeX toolchain works on a
fresh clone.
